# The icons beside the entries

Each file here is the mark of the service a provider connects to, which its entry declares under `icons`. Each mark is a trademark of its owner. It is shown only beside the provider's name, to tell a person which service a connection reaches, and implies no endorsement by its owner. The files are not covered by the Elastic License 2.0 of the rest of this repository: each is used under the licence or the terms its row names.

Every SVG file is written as one `<svg>` of one or more `<path>` elements, each with a `fill` and a `d`, and nothing else, which is what `iconTypeOf` of `src/entry/entry-icons.ts` accepts as SVG. Every PNG file is the brand's own file, byte for byte, as its row below names it, since the brand's rules ask for its marks to be used unaltered and the brand offers no SVG of that form. A file named `<mark>-dark.svg` is the same path drawn in white, for a dark background, where the brand's colour has less than 3:1 contrast with the fill a dark theme draws a mark on (the ratio WCAG 2.2 success criterion 1.4.11 sets for graphics).
