Third-party notices of Cedar's WebAssembly

Auto's runtime loads web/cedar_wasm_bg.wasm of the npm package @cedar-policy/cedar-wasm 4.14.0. Cedar's own licence and notice, which cover Cedar's own crates (cedar-policy, cedar-policy-core, cedar-policy-formatter and cedar-wasm), are Cedar-LICENSE.txt and Cedar-NOTICE.txt beside this file. This file gives the notices of every other crate compiled into that WebAssembly, in two parts.

1. The crates of Cedar's build: the source of github.com/cedar-policy/cedar at the tag v4.14.0, commit 5e54be8a16f3f346eb542e4feca587bfb962ebd1, the crate cedar-wasm with its default features for the target wasm32-unknown-unknown, as Cedar's cedar-wasm/build-wasm.sh builds the package, resolved from Cedar's Cargo.lock unchanged: its normal dependencies, and the build dependencies of Cedar's own crates, whose output is compiled in (lalrpop 0.22.2). The other build dependencies of the graph run only while it builds and leave no code in it, and development dependencies are not built.

2. The Rust standard library, as rustc 1.99.1 (58cf8f9c3 2026-10-13), the compiler the WebAssembly's producers section names, builds it for that target with the features backtrace and panic-unwind, from its own sources and the crates they vendor.

Each licence text and copyright line comes from the crate's own published package, gathered with cargo-about 0.9.3. Where a crate offers a choice of licences, MIT is taken, as its text in each package carries the crate's copyright line; where a crate declares more than one licence together, each is given. A text printed once is named again below rather than repeated.
